# ADR-005: Dimensional Modeling and SCD Strategy

- **Status:** Proposed
- **Date:** 2026-10-01
- **Decision Owners:** ShopAnalysis Project
- **Scope:** Analytical data model

## Context

ShopAnalysis requires a governed dimensional model with conformed dimensions and business facts.

The planned model includes order, order-item, payment, refund, shipment, marketing-touch, and advertising-spend facts. Customer history requires an explicit slowly changing dimension strategy.

## Decision Drivers

- Historical accuracy
- Metric consistency
- Auditability
