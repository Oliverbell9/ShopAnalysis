# ADR-003: Environment Strategy

- **Status:** Proposed
- **Date:** 2026-10-01
- **Decision Owners:** ShopAnalysis Project
- **Scope:** Development, CI, and production environments

## Context

ShopAnalysis requires separation between development, continuous-integration validation, and production-style workloads.

The project specification calls for DEV, CI, and PROD environments while also requiring the completed portfolio to remain reproducible after cloud trial resources expire.

## Decision Drivers

- Environment isolation
- Reproducibility
- Deployment safety
- Cost
- CI/CD compatibility
- Developer productivity
- Portfolio longevity
